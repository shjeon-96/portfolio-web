# Portfolio Web

Public portfolio website for job applications.

## Direction

This site uses a Product Console Portfolio / Engineering Ledger theme.

The first public version should include:

- Home
- Case Studies
- Engineering Changelog
- AI Workflow
- Skills
- About
- Resume link

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Local Workflow

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

## Deployment

Deploy with Vercel.

- Production branch: `main`
- Build command: `npm run build`
- Initial version should not require environment variables.
